# BLS75 Primality Test

The BLS75 primality test is a deterministic primality test designed for numbers of a specific form. It's particularly efficient for testing numbers of the form $$k \cdot 7^n \pm 5$$ where $$k$$ is small.

## Mathematical Foundation

The test is based on Lucas sequences and the following theorem:

Let $$n$$ be a positive integer of the form $$k \cdot 7^m \pm 5$$. Then $$n$$ is prime if and only if it satisfies certain congruence conditions involving Lucas sequences.

For a number $$n$$ of this form, we define:

$$
U_k(P,Q) = \frac{\alpha^k - \beta^k}{\alpha - \beta}
$$

where $$\alpha$$ and $$\beta$$ are the roots of $$x^2 - Px + Q$$.

## Theorem


Define $$n > 1$$. If for every prime factor $$q$$ of $$n-1$$, if there exists an integer $$a$$ such that $$ a^{n-1} \equiv 1 \pmod{n} $$ and $$a^{\frac{n-1}{q}} \not\equiv 1 \pmod{n}, $$ then $$n$$ is prime.

### Proof

To demonstrate that $$n$$ is prime, we need to show that $$\phi(n) = n-1$$, where $$\phi(n)$$ is the Euler totient function. More simply, we need to prove that $$n-1$$ divides $$\phi(n)$$. Assume, for contradiction, that this is not the case. Then there exists a prime $$q$$ and an exponent $$r > 0$$ such that $$q^r$$ divides $$n-1$$ but not $$\phi(n)$$. For this prime $$q$$, there must be an integer $$a$$ satisfying the conditions above. Let $$m$$ be the order of $$a$$ modulo $$n$$. Then $$m$$ divides $$n-1$$ (by the first condition) but not $$\frac{n-1}{q}$$ (by the second condition). Thus, $$q^r$$ divides $$m$$, which in turn divides $$\phi(n)$$—a contradiction that proves the theorem.

In this proof, we examined the group $$(\mathbb{Z}/n\mathbb{Z})^*$$, which, if it had the correct size, $$n-1$$, would indicate that $$n$$ is prime. We gathered sufficient information (the two conditions) to demonstrate that the group indeed has the correct size. This approach forms the foundation of all modern primality tests, whether they are as straightforward as the test above or as complex as those involving elliptic curves or number fields.

## Time and Space Complexity

The time complexity for testing a number $$n$$ is $$O(\log^2 n)$$, and the space complexity is $$O(\log n)$$.

```javascript
function modPow(base, exponent, modulus) {
    if (modulus === 1n) return 0n;
    
    let result = 1n;
    base = base % modulus;
    
    while (exponent > 0n) {
        if (exponent % 2n === 1n) {
            result = (result * base) % modulus;
        }
        base = (base * base) % modulus;
        exponent = exponent / 2n;
    }
    
    return result;
}

function lucasSequence(P, Q, k, n) {
    let U = 1n;
    let V = BigInt(P);
    let Qk = 1n;
    
    for (let bit of k.toString(2).slice(1)) {
        U = (U * V) % n;
        V = (V * V - 2n * Qk) % n;
        Qk = (Qk * Qk) % n;
        
        if (bit === '1') {
            const t1 = U * P;
            const t2 = V;
            U = (t1 + t2) * (1n / 2n) % n;
            V = (t1 * P + t2 * Q) * (1n / 2n) % n;
            Qk = (Qk * Q) % n;
        }
    }
    
    return [U, V];
}

function isForm7n5(n) {
    // Check if n is of form k * 7^m ± 5
    let temp = n;
    if (temp % 7n === 0n) {
        while (temp % 7n === 0n) {
            temp = temp / 7n;
        }
    }
    return Math.abs(Number(temp)) === 5;
}

function bls75Test(n) {
    // Convert to BigInt
    n = BigInt(n);
    
    // Handle small cases
    if (n <= 1n) return false;
    if (n <= 3n) return true;
    if (n % 2n === 0n) return false;
    
    // Check if n is of the correct form
    if (!isForm7n5(n)) {
        throw new Error("Number must be of form k * 7^m ± 5");
    }
    
    // Parameters for Lucas sequence
    const P = 3n;
    const Q = -1n;
    
    // Calculate (n+1)/2
    const k = (n + 1n) / 2n;
    
    // Compute Lucas sequence
    const [U, V] = lucasSequence(P, Q, k, n);
    
    // Check congruence conditions
    return U === 0n && V === 2n;
}

// Example usage:
console.log(bls75Test(5));     // true
console.log(bls75Test(47));    // true (7^2 - 5)
console.log(bls75Test(12));    // false
```
