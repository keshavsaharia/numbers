# Cosine Distance

Cosine distance is a measure of similarity between two strings by treating them as [vectors](/linalg/vectors), and computing the cosine of the angle between them. It is particularly useful for comparing documents or text strings where the order of words is not as important as their frequency.

## Mathematical Definition

The cosine distance $$d_c$$ between two strings $$s_1$$ and $$s_2$$ is defined as

<Center>
$$
d_c(s_1, s_2) = 1 - \cos(\theta) = 1 - \frac{\vec{s_1} \cdot \vec{s_2}}{|\vec{s_1}| |\vec{s_2}|}
$$
</Center>

The vectors $$\vec{s_1}$$ and $$\vec{s_2}$$ are representations of a string that can be created from an arbitrary strategy - character n-grams, word frequency counts, TF-IDF (Term Frequency-Inverse Document Frequency), or more popular recently, [word embeddings](/string/embedding). The computed value $$\theta$$ is the "angle" between the vectors, and $$|\vec{s}|$$ represents the magnitude of vector $$\vec{s}$$.

## Properties

- Cosine distance produces a value ranging from $$0$$ to $$2$$, where $$0$$ indicates identical strings and $$2$$ indicates completely different strings. 
- Cosine distance is symmetric, meaning the distance from string $$s_1$$ to $$s_2$$ is the same as from $$s_2$$ to $$s_1$$.
- Cosine distance does not satisfy the triangle inequality, making it a non-metric distance measure.
- Cosine distance is invariant to string length, making it particularly useful for comparing documents of different sizes.

## Applications

- In document similarity analysis, it helps identify similar documents regardless of their length. 
- For text classification tasks, it provides an effective way to categorize documents based on their content. 
- In information retrieval systems, it helps rank search results by relevance. 
- For plagiarism detection, where it can identify similar text passages across different documents. Additionally, it plays a crucial role in search engines, helping to match user queries with relevant documents in the index.

## Implementation

Cosine similarity is a measure of similarity between two vectors.

```typescript
function cosineSimilarity(A: number[], B: number[]): number {
    if (A.length !== B.length) {
        throw new Error('Vectors must be of the same length');
    }

    let dotProduct = 0;
    let magnitudeA = 0;
    let magnitudeB = 0;

    for (let i = 0 ; i < A.length ; i++) {
        dotProduct += A[i] * B[i];
        magnitudeA += A[i] * A[i];
        magnitudeB += B[i] * B[i];
    }

    return dotProduct / (Math.sqrt(magnitudeA) * Math.sqrt(magnitudeB));
}
```
