# vLLM models

vLLM supports a wide range of models, including:

- [LLaMA](https://huggingface.co/meta-llama/Llama-2-7b-chat-hf)
- [Mistral](https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.1)
- [GPT-2](https://huggingface.co/gpt2)
- [GPT-3](https://huggingface.co/gpt-3)
- [GPT-4](https://huggingface.co/gpt-4)
- [GPT-4o](https://huggingface.co/gpt-4o)

```bash
# Mixtral
--model mistralai/Mixtral-8x7B-Instruct-v0.1

# OpenHermes
--model teknium/OpenHermes-2.5-Mistral-7B

# LLaMA 3
--model meta-llama/Meta-Llama-3-8B-Instruct

# Phi-3
--model microsoft/phi-2
```
